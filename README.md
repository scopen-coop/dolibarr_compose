# How to use it ?
Check README into each folder but basically 
directory structure should be for exemple 
/.../dolibarr_compose_php84_nginx
/.../dolibarr/ => Clone of the dolibarr

Copy the ressource/documents into /.../dolibarr/
$chown -R www-data:www-data /.../dolibarr/documents

create your own conf.php base on ressource/conf.php
